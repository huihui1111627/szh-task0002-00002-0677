# 近地轨道碰撞风险推演中心

面向近地轨道卫星运行中心的碰撞风险推演 Web 应用：在三维轨道视图中连续呈现卫星、碎片与预测交会点；选择目标后突出其未来轨迹与风险时间窗；可调整变轨时刻、方向（径向 R / 沿迹 T / 法向 N）与幅度，实时重算燃料消耗、任务中断时间与新的碰撞概率；支持最多三套方案并排比较；当方案产生二次交会、燃料不足或通信窗口冲突时标出受影响对象；方案确认后形成推演节点，刷新或中断后可从最近确认节点继续。

纯前端、零构建、离线可用（Three.js 已本地化到 `vendor/`）。

## 运行

ES Module 需要通过 HTTP 访问（不能直接双击 `file://`）：

```bash
python3 -m http.server 8123
# 打开 http://127.0.0.1:8123/index.html
```

内核不依赖浏览器/DOM，可直接用 Node 跑单元测试：

```bash
npm test
```

## 使用

- **三维态势**：拖拽旋转、滚轮缩放；点击卫星/碎片/交会环/地面站可选中定位；主星带蓝色光环，基线轨迹为蓝色虚线，各方案轨迹用方案色实线，菱形为机动点火点，环形标记为交会点（红=高风险、橙=中、绿=低），进入 TCA±30 分钟风险窗时脉冲高亮。
- **时间轴**：播放/暂停、拖动游标，轨道上连续推演 72 小时；红色刻度为交会时刻，菱形为机动时刻。
- **交会列表**：展示每个交会的 TCA、最近距离、相对速度、Pc、风险时间窗，以及相对基线的 Pc 数量级变化。
- **变轨方案**：右栏新建方案后可增加任意次数的瞬时冲量机动，设置点火时刻与 R/T/N 三向速度增量（m/s），实时显示总 Δv、推进齐奥尔科夫斯基燃料消耗、点火时长、任务中断时间（含姿态建立与恢复）、最大 Pc，并给出可行/不可行结论。
- **冲突标注**：二次交会（未缓解的基线目标或新增近距离交会）、推进剂不足、与地面站通信窗口重叠的中断窗口都会在方案卡片和底部对比区标出受影响对象。
- **多方案比较**：勾选「加入并排比较」后，底部表格并列展示最多 3 套方案的全部指标与受影响对象。
- **推演节点**：方案满意后点「确认推演节点」，快照（方案、机动、时间、结论摘要）写入 `localStorage`；刷新、崩溃或关闭后重新打开，顶部节点条提供「从此节点继续」一键恢复。

## 场景

内置 72 小时、780 km 太阳同步主星「近星-1 号」，含 3 块特征碎片与 1 颗在轨卫星、4 个地面站。基线包含三次真实高风险交会：

| 目标 | TCA | 最近距离 | 相对速度 | 基线 Pc |
| --- | --- | --- | --- | --- |
| Cosmos-2251 碎片 | T+19.2h | ~0.4 km | ~1.8 km/s | ~2.2e-4 |
| FengYun-1C 碎片 | T+36.0h | ~0.3 km | ~9.1 km/s | ~1.7e-4 |
| Iridium-33 碎片 | T+51.5h | <0.01 km | ~0.06 km/s | ~4.3e-4 |

可尝试：T+6h 沿迹 +0.5 m/s 可缓解全部威胁；法向小冲量对 9 km/s 高速交会几乎无效；200 m/s 大冲量会触发推进剂不足；点火落在通信过境内会标红冲突。

## 物理模型

- 二体开普勒传播（`js/orbital.js`）：轨道根数 ↔ ECI 状态双向精确转换，机动按 RTN 坐标系瞬时冲量处理，分段重构根数继续传播。
- 两级交会扫描（`js/risk.js`）：5 s 粗扫标记凹陷区间并合并窗口，1 s 细扫 + 黄金分割定位最近点，兼容 9 km/s 高速掠过与慢速追越。
- 碰撞概率：垂直于相对速度的交会平面内短路径高斯近似，协方差随推演时长增长（RTN 三轴）。
- 燃料：齐奥尔科夫斯基方程（湿重 1220 kg、推进剂 95 kg、Isp 220 s、推力 22 N）。
- 任务中断：每次点火前 5 min 姿态建立 + 点火时长 + 后 10 min 恢复。
- 通信：4 个地面站 5° 仰角门限扫描过境窗口，与中断窗口求交。

```

css/style.css         样式
js/main.js            入口

js/view3d.js          Three.js 三维视图与拾取
js/ui.js              面板、时间轴、方案编辑、多方案对比
vendor/               本地 Three.js r160
tests/                Node 内置测试运行器的内核单测
```
